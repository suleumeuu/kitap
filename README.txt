C++ ОҚУ ПОРТАЛЫ
Автор: Найзағараева А.А.

Файлдар:
- index.html — негізгі бет
- style.css — дизайн
- app.js — интерактивтілік, навигация, іздеу, практика
- data.js — дәрістер мен зертханалардың деректері

Іске қосу:
1) Барлық файлды бір папкада сақтаңыз.
2) index.html файлын браузерде ашыңыз.
3) Интернет қажет емес (Google Fonts жүктелмесе, сайт жүйелік қаріппен де жұмыс істейді).

Ескерту:
Материалдар пайдаланушы ұсынған «Дәрістер жиынтығы.docx» және «Зертханалық жұмыстар.doc» құжаттарының құрылымы мен мәтініне сүйеніп жасалды.
